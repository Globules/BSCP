## Labs tips

Every lab from OAuth authentication has:

- OAuth login flow
- `/auth` authorization endpoint
- `client_id`
- `redirect_uri`
- `response_type`
- OAuth callback endpoint
- Access token or authorization code handling
- Weak validation or missing security controls
- Burp Proxy + Repeater required
- OAuth/OpenID configuration discovery
- Exploit server usage in most Practitioner labs
