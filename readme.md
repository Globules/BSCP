# BSCP Preparation Repository

> Comprehensive notes, methodologies, lab solves, decision trees, payloads, and exam preparation material for the Burp Suite Certified Practitioner (BSCP).

# Overview

This repository is entirely dedicated to preparing for the:

- Burp Suite Certified Practitioner (BSCP)
- PortSwigger Web Security Academy labs

It contains:

- Detailed lab solves
- Enumeration methodologies
- Exploitation chains
- Payload collections
- Decision trees
- Exam notes
- Practical attack workflows
- Burp Suite methodology
- Ressources for the labs and the exam (payload, tools, wordlist..)

The goal of this repository is to centralize everything required to efficiently prepare for the BSCP exam and improve practical web exploitation skills.
